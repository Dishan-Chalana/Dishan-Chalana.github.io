# Dishan Chalana - Portfolio

Personal portfolio website showcasing my professional experience, projects, and achievements as a Full-Stack Software Engineer.

## 🚀 About

This portfolio highlights my work in building scalable SaaS platforms, multi-tenant applications, and full-stack solutions using modern web technologies including React, Next.js, Node.js, Laravel, and cloud services.

## 🛠️ Tech Stack

- **Frontend:** React, Next.js, Tailwind CSS, Bootstrap, Material UI
- **Backend:** Node.js, Express, Laravel
- **Databases:** MongoDB, MySQL, MSSQL
- **Cloud & DevOps:** AWS, Azure, Docker, Git

## 📦 Installation

```bash
npm install
```

## 🏃 Running Locally

```bash
npm start
```

## 🌐 Deployment

```bash
npm run deploy
```
